# deutsch/it

Интерактивный курс немецкого языка для IT-студентов на **React + Vite**.

30 уроков в 6 главах, 119 объясняющих блоков, 313 словарных записей, 120 проверочных заданий и 30 заданий на собственный текст. Объяснения на русском, практика и примеры на немецком. Есть схемы, озвучивание, карточки для повторения, локальный прогресс и экспорт резервной копии.

Курс создан по тематической структуре пособия «Немецкий язык для IT-студентов» (сост. С. В. Платонова, 2017). Это самостоятельная переработка материала; оригинальный PDF в репозиторий не включён. Карта всех тем и исторические оговорки находятся в [BOOK-ANALYSIS.md](BOOK-ANALYSIS.md).

## Запуск

Установите Node.js 24 и откройте папку проекта в Visual Studio или другом редакторе.

```sh
npm install
npm run dev
```

Для установки строго по сохранённому lockfile:

```sh
npm install --global pnpm@11.25.0
pnpm install --frozen-lockfile
pnpm run dev
```

Поле `private: true` в package.json предотвращает случайную публикацию npm-пакета; оно не задаёт видимость репозитория GitHub.

## Публикация через GitHub Pages

1. Создайте публичный репозиторий и загрузите содержимое этой папки в ветку `main`, включая `.github/workflows/deploy.yml`.
2. В репозитории откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**.
3. Откройте **Actions → Publish Deutsch IT to GitHub Pages → Run workflow**, если первый запуск уже завершился до настройки Pages.
4. Дождитесь успешного выполнения workflow. Итоговая ссылка будет в разделе Deployments и в Settings → Pages.

Каждый следующий push в `main` повторно проверяет и публикует сайт. Путь к ресурсам вычисляется по `base_path` GitHub Pages, поэтому сборка работает и в подпапке репозитория. Для ожидаемого репозитория `Nurlan-Bakenbaev/deutsch-it-labor` адрес после успешной публикации будет `https://nurlan-bakenbaev.github.io/deutsch-it-labor/`. Сам этот адрес не подтверждает, что публикация уже выполнена.

Workflow использует стандартный `GITHUB_TOKEN`; отдельно сохранять токены для приложения не требуется. Не включайте в репозиторий исходный PDF, файлы `.env`, резервные копии прогресса, `node_modules`, `.git` другого проекта и служебную папку `.openai`.

Официальные инструкции: [Vite: GitHub Pages](https://vite.dev/guide/static-deploy.html#github-pages), [GitHub: custom workflows](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages).

## Проверки и сборка

```sh
pnpm run check
node scripts/check-render.mjs
pnpm run build --base /deutsch-it-labor/
```

`check-render` проверяет 129 страниц и состояний React на уровне SSR. Это не визуальная проверка в браузере. Последняя подтверждённая проверка и ограничения описаны в [VERIFICATION.md](VERIFICATION.md).

## Хранение данных и ограничения

Прогресс, черновики, тексты и сохранённые слова хранятся в `localStorage` этого браузера. При переходе с другого домена их можно перенести через экспорт и импорт в разделе «Мой прогресс». Автоматическая синхронизация между доменами и устройствами не реализована.

Проверка письма ищет основы обязательных слов и считает слова. Она не оценивает полноценно грамматику и смысл. Доступность озвучивания зависит от немецких голосов браузера/операционной системы. Шрифты загружаются из Google Fonts; без сети используются системные.

Структура: `src/App.jsx` — страницы, `src/styles.css` — интерфейс, `src/learning.js` — логика заданий и прогресса, `src/data/` — содержание курса.
